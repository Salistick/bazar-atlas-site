# Bazar Atlas

Catalogo estatico gerado de copias SQLite consistentes. O horario da base aparece na pagina.

Site: https://salistick.github.io/bazar-atlas-site/

`database/` contem os bancos SQLite gzip e um manifesto com hashes SHA-256.
`site-data/` contem os indices e detalhes gerados desses bancos. Nenhuma API do Tibia e consultada para ler o catalogo publicado.

Esta versao nao executa coletores. Atualizacoes de bids e novos registros dependem de uma nova publicacao.
Favoritos e tracker ficam no navegador; lembretes precisam da pagina aberta.
